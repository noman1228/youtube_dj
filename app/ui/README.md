# Editing EncoreMix in PySide6 Designer

Run `run_designer.bat` from the project root. It opens the main mixer, reusable
deck, and Karaoke Lab forms. Use **File → Open** for the other forms, or pass a
file to the launcher:

```powershell
.\run_designer.bat app\ui\search_dialog.ui
```

The application loads these files directly through [ui_loader.py](../ui_loader.py).
Save your Designer changes and restart the application with `python main.py`.
No `pyside6-uic` generation step is required.

## How forms connect to Python

Keep existing **objectName**, **pythonAttribute**, and **runtimeObjectName** values
when editing controls. `pythonAttribute` connects a widget to its existing
controller attribute; `runtimeObjectName` preserves the names used by the app's
theme. Layout names are also used by Python, especially `results_layout` and
the result card's `buttons` layout. New controls need Python signal connections.

The main form uses promoted `DeckWidget` and `SongSuggestions` components.
Open their separate forms to edit their contents. Both music decks use `deck.ui`;
Python supplies the side labels, accent colors and independent engines.
The playlist header's two rows are positioned in Designer for editing; its
existing Python resize behavior puts them on one row when space allows.

Promoted waveform, VU, video and projector-preview widgets appear as base-widget
placeholders in Designer. Their real painting, seeking, metering, video routing,
idle logo, singer overlay and beat pulse run in the app. Designer's preview
does not run the app's media engines or load the saved appearance theme.

All playback, search, related-song discovery, queue management, keyboard
shortcuts, automation, persistence and signal connections stay in the Python
controllers. Runtime text and state (such as the current title, selected theme,
fade mode and karaoke target) are filled in by those controllers. Standard Qt
file/color/singer-input/message dialogs and dynamic suggestion menus remain
generated by their existing Python actions.

## Offline verification

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

The Designer tests compile every form with Qt's UI compiler, load each form with
placeholder custom widgets, and check live controller bindings and actions.
Existing tests cover mixer, playlist, search, karaoke, waveform and media logic
using offline fixtures and mocks.
